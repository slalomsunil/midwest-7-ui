# Central AI Context

## Project Overview
**midwest-7-ui** is a React 19 frontend application that works in conjunction with a backend service. This context file provides shared AI understanding for both repositories to enable seamless cross-repository development, code review, and testing workflows.

## Architecture
- **Frontend**: React 19 application with Create React App structure
- **Backend**: Separate service repository (backend-specific context to be maintained there)
- **Integration**: RESTful API communication between UI and backend
- **Testing**: Jest and React Testing Library for frontend testing

## Technology Stack
- **React 19.1.1** - Latest React with modern functional components
- **JavaScript** - Primary development language
- **Jest + React Testing Library** - Testing framework
- **npm** - Package management
