# Copilot & Cursor Usage Standards

## Purpose
Establishes guidelines for using Copilot and Cursor in this project, ensuring consistent code review, testing, and context sharing.

## Usage Guidelines
- Always reference CENTRAL_AI_CONTEXT.md for shared context
- Use Copilot and Cursor for:
  - Code suggestions
  - Automated code review
  - Test generation and validation
- Follow documented code review and testing standards

## Code Review Standards
- All code changes should be reviewed using Copilot/Cursor suggestions
- Document review decisions and rationale in pull requests
- Use context from CENTRAL_AI_CONTEXT.md to inform reviews

## Testing Standards
- Generate and validate tests using Copilot/Cursor
- Ensure coverage for shared data models, API contracts, and business logic
- Document test results and gaps

## Maintenance
- Update standards as tools or workflows evolve
- Review and synchronize with CENTRAL_AI_CONTEXT.md regularly
