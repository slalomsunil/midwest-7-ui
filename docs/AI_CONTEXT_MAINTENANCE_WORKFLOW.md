# AI Context Maintenance Workflow

## Purpose
Describes the process for keeping AI context documentation current using the context-refresher module.

## Workflow Steps
1. Run context-refresher to analyze codebase and documentation changes
2. Update CENTRAL_AI_CONTEXT.md and related docs as needed
3. Review changes with team and confirm accuracy
4. Commit updates and document rationale
5. Schedule regular context reviews (e.g., quarterly or after major changes)

## Tools
- ae-toolkit/context-refresher module
- Copilot and Cursor for suggestions and validation

## Best Practices
- Always validate context updates with both UI and backend teams
- Document all context changes and review decisions
- Use gap analysis to identify missing or outdated context
